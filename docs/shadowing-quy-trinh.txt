QUY TRÌNH TẠO BÀI SHADOWING TỪ LINK YOUTUBE
==========================================

Nguyên tắc: chữ tiếng Trung chỉ lấy từ PHỤ ĐỀ (phụ đề dạng chữ của YouTube, hoặc phụ đề in sẵn trên hình).
Không dùng Whisper / nghe-chép (người dùng yêu cầu, 2026-11-27). Tiết kiệm token: máy làm hết, Claude chạy lệnh + đọc 1 dòng kết quả.

Công cụ (mã nguồn mở, miễn phí, chạy trên máy):
  - yt-dlp          : thông tin video, phụ đề dạng chữ, tải video 720p (không tiếng) để OCR.  pip install yt-dlp
  - RapidOCR        : mô hình PaddleOCR đọc phụ đề in trên hình.                             pip install rapidocr-onnxruntime
  - opencv-python   : đọc khung hình (cài kèm RapidOCR).
  - opencc-js       : phồn thể → giản thể (có trong app).
  - pinyin-pro      : app tự thêm pinyin theo từng từ khi hiển thị.
  - Dịch: Sonnet (agent) dịch theo ngữ cảnh cả tập, kèm bảng tên .cache/shadowing/glossary.txt.

A. Video CÓ phụ đề dạng chữ:
  node scripts/shadowing/make-lesson.mjs "<link>" [--title "…"] [--playlist "…"]
  → OK <id> | N câu | … (nếu dịch máy hết lượt: dịch phần .cache/shadowing/<id>.todo.txt rồi --apply <id>)

B. Video có phụ đề IN TRÊN HÌNH (make-lesson báo "CẦN OCR"):
  1. Tải video:  python -m yt_dlp -f "bv*[height<=720][ext=mp4]" -o ".cache/shadowing/v_<id>.%(ext)s" <link>
  2. OCR:        python scripts/shadowing/ocr-subs.py .cache/shadowing/v_<id>.mp4 .cache/shadowing/ocr_<id>
                 (đọc dải phụ đề đáy hình, tách chữ trắng, chỉ đọc khi phụ đề đổi; lưu ảnh crop_<giờ>.png của dòng chưa chắc)
                 Nhiều tập: .cache/shadowing/ocr-one.sh <id> (tải → OCR → xoá video), chạy 4 tập song song bằng xargs -P 4.
  3. Chuẩn bị:   node scripts/shadowing/ocr-to-lesson.mjs <id>   → .cache/shadowing/<id>.fuse.txt
                 (mỗi dòng: số, giờ, độ tin cậy, chữ OCR, đường dẫn ảnh crop nếu có)
  4. Sonnet (agent) đọc fuse.txt, MỞ ẢNH crop của dòng chưa chắc để chép đúng chữ trên màn hình, bỏ dòng trùng (DEL),
     dịch Việt theo ngữ cảnh → .cache/shadowing/<id>.fused.txt (số<TAB>chữ Trung<TAB>bản dịch | số<TAB>DEL)
  5. Ghép:       node scripts/shadowing/ocr-to-lesson.mjs --apply <id>   → public/shadowing/<id>.json (+ rev mới để app tự nạp lại)

Lưu ý:
  - Tải nhiều video liên tục → YouTube chặn tạm (HTTP 429): nghỉ 10–45 phút rồi thử lại, tải cách nhau vài phút.
  - OCR 720p mất khoảng 1,4× thời lượng video mỗi tập (CPU); máy 12 nhân chạy 4 tập song song.
  - Video tiếng Quảng Đông (粵語) → báo người dùng chọn bản 国语/普通话.
  - Push chỉ khi người dùng bảo push.
